# 💬 Chat Colaborativo en Tiempo Real con WebSockets

Este proyecto implementa un **sistema de chat colaborativo** que permite la comunicación entre múltiples usuarios en tiempo real utilizando **WebSockets**.  
Forma parte de la Actividad 5 del curso y está construido con **Node.js**, **Express** y **ws**, acompañado de un cliente **SPA** en HTML, CSS y JavaScript.

---

## 🚀 Características principales

✔️ Comunicación en tiempo real usando **WebSockets**  
✔️ Múltiples usuarios conectados simultáneamente  
✔️ Envío y recepción instantánea de mensajes  
✔️ Nombre de usuario personalizado o asignado automáticamente  
✔️ Notificación cuando un usuario se conecta o desconecta  
✔️ Historial básico de mensajes (opcional según el docente)  
✔️ Interfaz web simple y fácil de usar
